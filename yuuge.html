Problem

就活、こんな悩みありませんか？

合同説明会は情報過多で疲れる、ナビサイトは同じような文言ばかり、OB訪問は敷居が高い。「本当に自分に合う会社」を見つける手段が見つからない。

01
合同説明会は「聞くだけ」で終わる
100社以上が並ぶブースで名刺交換して、5分話して、資料もらって終わり。あれで「その会社の空気」まで分かるはずがない。
02
ナビサイトはどの会社も同じに見える
「若手が活躍できる」「風通しがいい」「グローバル」「成長機会」。どの会社の説明も似た文言。本当の違いは、中の人と話さないと分からない。
03
OB訪問は敷居が高い
アポ取って、カフェで1対1、質問を用意して。「意識高い」感じの就活生じゃないと動けない。そこまでの熱量、まだない。
Compare

既存の情報収集方法との、違い。

合同説明会・ナビサイト・OB訪問。それぞれ役割はあるけど、「小人数で本音で議論する」場所はどこにもない。

だから「少人数で本音で話せる、対話中心の場」をつくりました。
What's this?

ゆうげの若き熱論会とは。

同世代の大学生25人と、企業の若手社員5〜10人が集まって、1つのテーマで語り合う夕方2時間の対話イベントです。プレゼンでも一方通行の説明でもなく、少人数で本音で議論できる場。

Value Architecture

3つの時間軸で、企業と学生の関係を育てる。

ゆうげの若き熱論会は、単発のイベントで終わりません。当日の対話 → 中期の自発的接点 → 長期の関係構築という3つの時間軸で、企業ブランドと若者の関係を育てる場です。

PHASE 1 — Short-term
短期（イベント当日）
  • 質の高い対話
  • 学生の知的刺激
  • 企業文化の伝達
  • 採用色を抑えた本音の対話
  • 企業ブランドの浸透
PHASE 2 — Mid-term
中期（1〜3ヶ月）
  • 学生による自発的な企業選考エントリー
  • インターン応募
  • SNSでの口コミ拡散
PHASE 3 — Long-term
長期（6〜12ヶ月）
  • 新卒採用候補としての継続接点
  • 競合より早期のリレーションシップ構築
  • 採用ブランディングの定着
3つの時間軸を通じて、参加企業のブランドと質の高い若者の関係を育てる。それがこのイベントの本質です。

Themes

どんなテーマで議論するか。

企業のニーズに合わせて、事前ミーティングで最終決定。学生の興味を惹きつけやすく、解が一意に定まらないテーマを推奨。

Theme 1 — 教育
AI時代に、学校という装置はまだ機能するのか
Theme 2 — 就活/採用市場
就活というシステムの賞味期限
Theme 3 — 地方
AI時代における地方の在り方とは？
Theme 4 — AI
AI時代に、人間が残すべきもの
過度な事業説明や採用色の強調は避け、学生の知的好奇心に響くトーンを重視。集客を最大化するため、複合テーマ（例：地方×AI）も推奨。

FAQ

よくある質問。

参加前に気になることを、まとめました。

参加費はかかりますか？
完全無料です。当日追加でかかるお金もありません。
1人で参加しても大丈夫ですか？
大丈夫です。1人参加の学生も多いです。運営が話しやすい場を設計しているので、知り合いゼロでも自然に馴染めます。
大学2〜3年生じゃないと参加できませんか？
大学2〜3年生が中心ですが、大学1年生・4年生・大学院生も歓迎します。「就活の前に企業のリアルを知りたい」気持ちがあれば参加OK。
服装は何がいいですか？
私服でOK。スーツで来る必要はありません。カジュアルな対話イベントです。
食事は出ますか？
軽食とドリンクを用意しています。夕方の時間帯なので、お腹すいた状態にはならないように運営が調整します。
途中で帰ってもいいですか？
OKです。予定があれば途中退出も歓迎。無理せず来られる範囲で参加してください。
企業側は誰が来ますか？
その回に参加する企業の若手社員5〜10人が中心。人事だけでなく、事業側・エンジニア・営業など様々な職種の若手が参加します。
選考や就活オファーに繋がりますか？
対話イベントなので、その場での選考はありません。ただし、興味があれば連絡先を交換して、後日カジュアル面談等に発展することはあります（学生の同意ベース）。
キャンセルはできますか？
申込後のキャンセルは、開催3日前まではフォームからご連絡ください。それ以降は、可能な限り事前にメールでお知らせください（キャンセル料はかかりません）。
